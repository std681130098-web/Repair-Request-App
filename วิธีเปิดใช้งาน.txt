วิธีเปิดใช้งานระบบแจ้งซ่อมออนไลน์
=====================================

1) แตกไฟล์ Backup.zip ออกมา จะได้โฟลเดอร์ repair-system

2) เปิด CMD ในโฟลเดอร์นั้น เช่น "C:\Users\user\repair-system"

3) ติดตั้งไลบรารีที่ต้องใช้ (ทำครั้งเดียว)
   pip install -r requirements.txt

4) สั่งรันเซิร์ฟเวอร์
   python manage.py runserver

5) เปิดเบราว์เซอร์แล้วพิมพ์  127.0.0.1:8000


บัญชีสำหรับเข้าใช้งาน (รหัสผ่าน 1234 ทุกบัญชี)
-----------------------------------------------
   ผู้ดูแลระบบ  : admin            รหัสผ่าน 1234
   ช่างซ่อม     : tech1 , tech2    รหัสผ่าน 1234
   ผู้แจ้งซ่อม  : user1 , user2    รหัสผ่าน 1234

หน้าผู้ดูแลระบบ (Django admin) อยู่ที่  127.0.0.1:8000/admin/
เข้าด้วย  admin / 1234


ถ้าเข้าหน้า admin ไม่ได้ หรือลืมรหัสผ่าน
-----------------------------------------
   พิมพ์คำสั่งนี้ใน CMD เพื่อรีเซ็ตบัญชีแอดมินกลับเป็น admin / 1234

   python manage.py create_admin --all

   หรือถ้าอยากตั้งรหัสผ่านเอง
   python manage.py create_admin --password รหัสที่ต้องการ


ถ้าฐานข้อมูลหาย หรืออยากเริ่มใหม่พร้อมข้อมูลตัวอย่าง
------------------------------------------------------
   python manage.py migrate
   python manage.py seed_data


หมายเหตุ: รหัสผ่าน 1234 ใช้สำหรับการเรียน/ส่งงานเท่านั้น
ถ้าเอาไปใช้งานจริงต้องเปลี่ยนรหัสผ่านทันทีหลังเข้าระบบครั้งแรก
